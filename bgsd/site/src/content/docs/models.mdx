BGSD separates **who reasons** (the Conductor) from **who executes** (Pipeline Agents and verifiers). **Every new session** asks which worker/executor model paths to use through a Claude Code–style native selector. Doctor validates afterward — it never chooses for you.

Resume rehydrates the contract from `run.json` and skips setup selectors.

## Every-session selectors

Native UI only (`AskUserQuestion` / `request_user_input`). Never prose like “which model?”.

### Step 1 — recommended path preset (single-select)

Recommended option is listed first.

| Option | Meaning | Default flags |
| --- | --- | --- |
| **Claude Code only (Recommended)** | Opus 5 for build and evaluation | `--no-cursor --profile claude` (also the no-flag default) |
| **Cursor workers** | Composer routine + Grok hard via `cursor-agent` | `--cursor` |
| **Claude + Cursor** | Conductor on Claude; Cursor workers for units | `--cursor --profile claude` |
| **Claudex** | Claude + Codex hybrid (`claude-openai` or `openai-claude`) | `--no-cursor --profile <choice>` |
| **Codex only** | GPT 5.6 Sol at **high** effort | `--no-cursor --profile openai --build-effort high --evaluate-effort high` |
| **Custom mix…** | Continue to Step 2 multi-select | assembled from selections |

### Step 2 — executor model paths (multi-select)

Shown for **Custom mix…**, or when confirming overrides. Built-in free-form **Other** accepts custom ids (Doctor must validate).

| Option | Model id | Notes |
| --- | --- | --- |
| **Claude Opus 5 (Recommended)** | `claude-opus-5` | Claude Code workers; high effort (default executor) |
| **Cursor CLI · Composer 2.5 Standard** | `composer-2.5` | Routine Cursor lane — never Fast |
| **Cursor CLI · Grok 4.5 Standard** | `cursor-grok-4.5-high` | Hard Cursor lane — never Fast |
| **GPT 5.6 Sol · high** | `gpt-5.6-sol` | Codex workers at **high** effort (not medium) |
| **Custom…** | free-form | `--build-model` / `--evaluate-model` / cursor model flags |

The Conductor is your live session model. Start on Opus 5 when you want it to orchestrate — that choice is independent of the executor preset.

:::caution[No silent Fast or Auto]
Fast variants and Auto are never selector options and never silently selected. Doctor fails closed if Standard versus Fast cannot be distinguished.
:::

## Recommended paths (what to pick)

| Path | When to use | Conductor | Workers |
| --- | --- | --- | --- |
| **Claude Code only** | Everyday BGSD — default executor path | Any harness session (Opus 5 if you want it to orchestrate) | Opus 5 build + eval |
| **Cursor workers** | Prefer Cursor Agent CLI workers | Any harness session | Composer 2.5 + Grok 4.5 (hard + reason) |
| **Claude + Cursor** | Claude as Advisor; Cursor Agent for grunt work | Claude Code | Composer / Grok |
| **Claudex** | Want Claude build + OpenAI eval (or reverse) | Claude or Codex | Hybrid lanes under `--no-cursor` |
| **Codex only** | OpenAI-only; Sol at high reasoning | Codex | `gpt-5.6-sol` @ high |
| **Custom mix** | You know exact model ids / unusual combos | Any | Your multi-select |

## Role contract

| Role | Model | Chosen at |
| --- | --- | --- |
| **Conductor** | Your live session model | Session start — BGSD never replaces it |
| **Claude/Codex workers** | Opus 5 / Sol (effort from preset) | Default path, Claude-only, Claudex, Codex-only, or custom |
| **Routine Cursor workers** | Composer 2.5 Standard (`composer-2.5`) | `--cursor` / multi-select |
| **Hard Cursor workers** | Grok 4.5 Standard (`cursor-grok-4.5-high`) | Conductor assignment with recorded reason |
| **Verifiers** | Evaluation lane (Claude/Codex) or deterministic-first + Composer (Cursor) | Session policy |

## Default Claude/Codex routing

Default workers (no `--cursor`):

```json
"model_contract": {
  "profile": "claude",
  "routing": "fixed",
  "build": { "provider": "claude", "model": "claude-opus-5", "effort": "high" },
  "evaluate": { "provider": "claude", "model": "claude-opus-5", "effort": "high" }
}
```

## Cursor routing (`--cursor`)

When Cursor workers are enabled:

```json
"cursor": {
  "enabled": true,
  "models": {
    "routine": "composer-2.5",
    "hard": "cursor-grok-4.5-high"
  }
}
```

Doctor validates both selectors against `cursor-agent --list-models`.

**Hard assignments require a reason.** Ambiguous scope, cross-cutting changes, security-sensitive work, etc.

## Claude/Codex profiles

| Profile | Build lane | Evaluate lane |
| --- | --- | --- |
| `claude` | Claude | Claude |
| `openai` | OpenAI | OpenAI |
| `claude-openai` | Claude | OpenAI |
| `openai-claude` | OpenAI | Claude |

Pipeline defaults when not overridden by selectors: Claude lanes use Opus 5 at **high** effort; OpenAI lanes use GPT-5.6 Sol at **medium** effort. The **Codex only** preset and the **GPT 5.6 Sol · high** multi-select option force Sol to **high** via `--build-effort high --evaluate-effort high`.

### Fixed vs adaptive

| Mode | Behavior |
| --- | --- |
| `fixed` (default) | All build units use the selected build model |
| `adaptive` | Conductor writes per-unit assignment + reason; missing assignment → heavy model |

Evaluation-lane routing stays **fixed** — verification quality is never traded for tokens.

## CLI overrides

```sh
# Claude Code only (recommended / default)
node bgsd/scripts/session.mjs --prompt "Build an audit log" --no-cursor --profile claude

# Cursor workers (opt-in)
node bgsd/scripts/session.mjs --prompt "Build an audit log" --cursor

# Codex only — Sol high
node bgsd/scripts/session.mjs --prompt "..." \
  --no-cursor --profile openai \
  --build-effort high --evaluate-effort high

# Custom ids
node bgsd/scripts/session.mjs --prompt "..." \
  --no-cursor --profile claude-openai \
  --build-model claude-opus-5 \
  --evaluate-model gpt-5.6-sol \
  --build-effort high --evaluate-effort high
```

All model ids are provider-validated. API-key environment variables are scrubbed from child processes.
