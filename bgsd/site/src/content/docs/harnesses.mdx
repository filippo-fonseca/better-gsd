BGSD is **harness-agnostic**. The Conductor is markdown under `bgsd/commands/` plus plain Node scripts. Slash commands (`/bgsd-sesh`, `/bgsd-doctor`, …) are the preferred front door in every host that surfaces them.

## Slash commands everywhere

| Host | How `/bgsd-*` shows up |
| --- | --- |
| **Claude Code** | Plugin marketplace → skills + slash commands |
| **Cursor** | Repo / plugin skills and command markdown — type `/bgsd-` in chat |
| **Codex** | Codex plugin → skills from `bgsd/skills/` |

If a host doesn't list a command yet, run the same flow via:

```sh
node bgsd/scripts/conductor.mjs "<what to build>"
```

That loads `bgsd/commands/bgsd-sesh.md` and exports `CLAUDE_PLUGIN_ROOT` so every script path works.

## Claude Code

```sh
claude plugin marketplace add filippo-fonseca/better-gsd
claude plugin install bgsd@better-gsd
```

```
/bgsd-sesh "Build an audit log"
```

- Conductor = your live Claude session
- Default workers = Cursor Agent CLI (unless you pick Claude/Codex-only paths)
- Native `AskUserQuestion` selectors

## Cursor

Open this repo (or install the plugin where Cursor discovers skills). Prefer slash commands:

```
/bgsd-sesh "Build an audit log"
/bgsd-doctor
/bgsd-status
```

Fallback:

```sh
node bgsd/scripts/conductor.mjs "Build an audit log"
```

- Conductor = your live Cursor session model
- Default workers = Claude Opus 5 (`--no-cursor`); opt in to `cursor-agent` with `--cursor`
- Doctor checks the selected backend (Claude/Codex login, or Cursor browser login + Standard selectors)

## Codex

```sh
codex plugin marketplace add filippo-fonseca/better-gsd
codex plugin add bgsd@better-gsd
```

```
/bgsd-sesh "Build an audit log"
```

- Conductor = your live Codex session
- Same command set and Node engine as Claude Code

## Harness detection

`BGSD.md` → `harness.active` defaults to `"auto"`:

| Value | Meaning |
| --- | --- |
| `auto` | Detect from env (`CLAUDE_PLUGIN_ROOT`, Codex, Cursor, …) |
| `claude` / `codex` / `cursor` | Pin explicitly |

## Choosing a host

| If you… | Do this |
| --- | --- |
| Live in Claude Code | Plugin + `/bgsd-sesh` |
| Live in Cursor | Repo open + `/bgsd-sesh` (or `conductor.mjs`) |
| Live in Codex | Plugin + `/bgsd-sesh` |
| Need CI / scripts | `node bgsd/scripts/session.mjs` |

:::note[Equal backends]
`--no-cursor` / Claude-only and Codex-only presets are the **default** full pipelines. Cursor workers (`--cursor`) are an equal opt-in. Doctor, routing, and verification contracts match either path.
:::
