Slash commands are the primary UI. They work in **Claude Code**, **Cursor**, and **Codex** once the plugin / repo is available. Every command has a Node fallback under `bgsd/scripts/` when you need scripts or CI.

## Core

| Command | Purpose |
| --- | --- |
| `/bgsd-sesh` | Start a selector-driven session (main entrypoint) |
| `/bgsd-doctor` | Preflight CLI, subscription, selectors, GSD |
| `/bgsd-init` | First-time repo setup (`next`, `.bgsd/`, `BGSD.md`) |
| `/bgsd-status` | Live workers, phases, blockers |
| `/bgsd-gui` | Open the live dashboard |

```
/bgsd-sesh "Add export filters"
/bgsd-sesh --feature "Ship billing portal"
/bgsd-doctor
```

## Session control

| Command | Purpose |
| --- | --- |
| `/bgsd-pause` | Park the session cleanly |
| `/bgsd-resume` | Continue a paused / interrupted session |
| `/bgsd-feedback` | Re-run fixes from review findings (`--fast` optional) |
| `/bgsd-user-eval` | Boot integrated servers for manual review |
| `/bgsd-run` | Project-mode orchestrator (large prompt → DAG) |
| `/bgsd-run-agent` | Execute one isolated build-lane unit |
| `/bgsd-verify` | Computer-use verification against criteria |
| `/bgsd-integrate` | Loop 2 integration pass |

## Queue & memory

| Command | Purpose |
| --- | --- |
| `/bgsd-queue` | Add / list / drain the fix-stream backlog |
| `/bgsd-capture` | Hyperpolymath capture → queue |
| `/bgsd-recall` | Search past session history |
| `/bgsd-generate-brief` | Hand-off brief for the next session |
| `/bgsd-modify-memory` | Persist a preference into `BGSD.md` |
| `/bgsd-token-usage` | Token burn by lane / model / unit |

## Housekeeping

| Command | Purpose |
| --- | --- |
| `/bgsd-clean` | Prune stale worktrees / merged branches |
| `/bgsd-changelog` | Aggregate per-agent changelog into the PR |
| `/bgsd-escalate` | Confidence-gated human escalation |
| `/bgsd-remote` | HTTP bridge to observe / drive a session off-box |

## Script equivalents

| Surface | Script |
| --- | --- |
| `/bgsd-sesh` | `node bgsd/scripts/conductor.mjs "…"` or `session.mjs` |
| `/bgsd-doctor` | `node bgsd/scripts/doctor.mjs` |
| `/bgsd-queue` | `node bgsd/scripts/queue.mjs …` |
| `/bgsd-recall` | `node bgsd/scripts/kb.mjs --query "…"` |
| `/bgsd-status` | `node bgsd/scripts/status.mjs` (when available) |

## Session flags (`/bgsd-sesh` / `session.mjs`)

| Flag | Purpose |
| --- | --- |
| `--quick` / `--feature` / `--project` | Workflow depth |
| `--plan-only` | Route without spawning |
| `--no-cursor` | Claude Code / Codex workers |
| `--profile` | `claude`, `openai`, `claude-openai`, `openai-claude` |
| `--build-model` / `--evaluate-model` | Custom model ids |
| `--build-effort` / `--evaluate-effort` | e.g. Sol **high** |
| `--routing` | `fixed` (default) or `adaptive` |
| `--cursor-routine-model` / `--cursor-hard-model` | Cursor selector overrides |
| `--proxy` | CLIProxyAPI via Claude harness |

## Examples

```
/bgsd-sesh "Add export filters"
/bgsd-sesh --project "Migrate auth to sessions"
/bgsd-queue add --title "Fix empty state" --body "Settings blank on mobile"
/bgsd-status
```

```sh
node bgsd/scripts/session.mjs --prompt "Add export filters" --feature
node bgsd/scripts/session.mjs --prompt "…" --no-cursor --profile openai \
  --build-effort high --evaluate-effort high
```
