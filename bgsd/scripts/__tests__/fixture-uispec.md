# UI Specification — Example App

## Overview

This document describes the acceptance criteria for the example feature.

## Success Criteria

- [ ] CRIT-01: The page loads without any console errors.
- [ ] CRIT-02: The navigation menu renders all five top-level items.
- [ ] CRIT-03: Clicking "Submit" fires a POST request to `/api/submit` and returns 200.
- [x] CRIT-04: The footer displays the correct copyright year.
- [ ] Users can reset their password via the email flow.

## Non-functional Requirements

- Response time under 200ms at p95.
- Accessible at WCAG 2.1 AA level.
