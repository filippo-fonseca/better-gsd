# BGSD v2

BGSD combines a live Conductor with independent build and evaluation lanes. The
Conductor is whichever Claude Code or Codex session you started. It scopes the
work, authors seed plans, makes advisory decisions, and asks every user-facing
question through the native selector UI.

Quick is a lightweight adaptive Pipeline Agent run: the Conductor writes a
compact plan, chooses one or more direct workers, and steers them through
evidence without invoking GSD. The workers edit and repair code in isolated
worktrees; the Conductor does not. Feature and Project build lanes run full GSD
workflows under the same advisory contract at every plan, commit, blocker, and
verification checkpoint. The evaluation lane performs Loop 1, Loop 2, and final
fresh review. Both lanes use existing subscriptions, not provider API keys.

| Mode | Best for | Build path | Evidence |
| --- | --- | --- | --- |
| Quick | one contained fix | adaptive direct workers; no GSD | worker verify/fix plus Conductor review |
| Feature | a scoped change | a few units, integrate when needed | Loop 1 plus Loop 2 when applicable |
| Project | multi-surface product work | discuss, DAG, waves, full GSD units | Loop 1, Loop 2, fresh review, human gate |
