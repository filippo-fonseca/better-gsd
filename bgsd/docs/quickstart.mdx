# Quickstart

Install BGSD for the harness you use:

```sh
claude plugin marketplace add filippo-fonseca/better-gsd
claude plugin install bgsd@better-gsd

codex plugin marketplace add filippo-fonseca/better-gsd
codex plugin add bgsd@better-gsd
```

Start `bgsd-sesh` inside a git repository. The session selector chooses one of
four provider profiles, fixed or adaptive build routing, verification depth, and
any custom provider-valid model id. BGSD Doctor verifies subscription login and
installs `gsd-core` for every selected runtime.

```sh
node bgsd/scripts/session.mjs --prompt "Add export filters" --profile claude-openai
```

The normal path launches the relevant CLI directly. Use `--proxy` only when you
want Claude Code's harness to call a foreign model through a local verified
CLIProxyAPI endpoint. Set `BGSD_PROXY_URL` and `BGSD_PROXY_TOKEN`; the doctor
checks `/v1/models` before work starts.
