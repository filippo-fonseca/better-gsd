# Feedback and changelog

Feedback becomes a bounded fix pass. BGSD groups related defects, dispatches
the build lane, and re-runs the configured evaluation lane when verification is
required. A feedback plan records `model_hint: "build-lane/default"`; the real
model comes from the current session contract or an explicit adaptive assignment.

Every completed unit contributes a structured changelog entry with its concrete
model, lane, verification evidence, and commit history.
