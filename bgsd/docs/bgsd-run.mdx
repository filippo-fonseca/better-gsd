# Running BGSD units

A decomposed unit receives an isolated git worktree, a full GSD workflow, an
optional Conductor seed, and a durable control file. Build-lane agents make
focused commits. They never merge to `next` or `main` themselves.

Unit difficulty controls phase depth such as research, UI work, and review. It
does not select a provider model. In adaptive mode, only an explicit Conductor
assignment can choose the light catalog; otherwise the heavy build model runs.

After Loop 1 evidence is clean, BGSD integrates in dependency order and runs
Loop 2 when the assembled change needs integration validation.
